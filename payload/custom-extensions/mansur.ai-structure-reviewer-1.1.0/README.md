# AI Structure Reviewer

Глобальное расширение для **Antigravity IDE** и **VS Code**, которое анализирует структуру текущего открытого проекта (React, TypeScript, Vite, Jotai, Zustand, Redux Toolkit и др.) и показывает интеллектуальные рекомендации по улучшению расположения файлов.

## Главные принципы
- **Только анализ и рекомендации:** Расширение **ничего не перемещает, не удаляет и не изменяет** в коде проекта. Все исправления делает разработчик.
- **Глобальная работа:** Устанавливается через VSIX и автоматически работает в любых проектах на любых дисках.
- **Интеграция в Explorer:** Секция **AI Структура** прямо в проводнике рядом со стандартными секциями.

## Уровни рекомендаций
- ✅ **Правильно** — структура логичная, всё на своих местах.
- 🟡 **Можно улучшить** — структура допустима, но есть более понятный или лаконичный вариант.
- 🔴 **Неправильная структура** — файл явно находится не на своём месте (например, хук или сервис внутри папки UI-компонентов).

## Команды
- `AI Structure Reviewer: Analyze Project` — Запустить анализ структуры активного проекта.
- `AI Structure Reviewer: Refresh` — Обновить результаты анализа.
