# Runtime Monitor for Antigravity IDE

Профессиональная панель реального времени для отладки Console и Network прямо внутри Antigravity IDE без необходимости постоянно переключаться в Chrome DevTools.

## Возможности
- **Live Console:** вывод `console.log`, `info`, `warn`, `error`, `debug`, `table`, `group`, ошибок и stack trace.
- **Интерактивные объекты:** древовидное раскрытие объектов и массивов с ленивой подгрузкой свойств.
- **Переход к коду:** клик по источнику (например, `Home.tsx:42`) мгновенно открывает файл в редакторе.
- **Live Network:** отслеживание Fetch/XHR, GET, POST, PUT, DELETE с кодами статусов, временем, заголовками и телом ответа.
- **Детектор повторных запросов:** обнаружение дублирующихся вызовов API.
- **Сравнение ответов (Response Diff):** визуальный diff между двумя JSON-ответами.
- **Закрепление (Pin/Bookmark):** сохранение важных логов и запросов при очистке.
- **Безопасность:** маскирование токенов и паролей, изоляция debug-профиля, работа только по localhost (127.0.0.1).
